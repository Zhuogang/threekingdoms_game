## 0. 摘要

- **特别战役**：开始画面单独一张卡"陈仓之战 · 建兴六年冬"。不进大地图，没有内政、征兵、外交和武将成长，只有这一场攻城战。一局约 45–60 分钟。
- **玩家扮演蜀军**：诸葛亮率约两万人，要在余粮耗尽前攻下陈仓（攻占帅府前庭）。魏军由 AI 指挥，郝昭领千余人守城。
- **攻城和野战不同在哪**：城墙只能靠云梯或填平城堑后攀上去；城门要用冲车撞破；人再多，一次也只有一段正面能接战（§4.3）。守方用火箭烧器械、石磨砸冲车、连夜筑重墙。
- **"精美"的标准**：一场仗从开场劝降到结局完整走通，画面统一，规则看得懂。宁可少做几个系统，也不留半成品。地道、扮演魏军、骑兵追击都放到 v0.2（§1）。
- **不动野战**：攻城的规则、渲染和界面都放在新的 `src/siege/`。v0.4 的代码只改开始画面的入口和开发预览页的开关（§9）。

## 3. 一局怎么玩

1. **开始画面**：在"新战役"旁边加一张"特别战役 · 陈仓之战"卡，点开是简介和"开始"按钮；有存档时多一个"继续"。
2. **开场**（可跳过）：两张插画加对白。靳详在城下两次劝降，郝昭在城楼上两次拒绝；然后诸葛亮下令攻城。
3. **部署**：蜀军 10 支部队在大营和营前部署区，玩家可以换位；两座工棚空着。魏军已经在城内和墙上。
4. **第一幕：云梯冲车**（第 1 日起）。工棚能造云梯、冲车、土车。魏军用火箭烧云梯，用石磨砸冲车。
5. **第二幕：井阑重墙**（第 6 日起；如果第一幕已经被毁掉两件器械，提前开始）。诸葛亮献策，工棚多出井阑；魏军开始在城内筑重墙。
6. **结局**：
   - **破城**：日终有蜀军站在帅府前庭，或魏军全灭、溃散。架空结局"陈仓陷落"。
   - **史实结局**：第 20 日日终仍未破城，粮尽退兵，张郃将至；结局画面交代王双追击被斩。
   - **溃败**：蜀军全军溃散，或本阵被击溃。
   - **撤军**：玩家随时可以下令撤军，算作史实结局，但评价更低。
7. **战后总结**：双方伤亡、器械造了多少、毁了多少、用了几日，和史实对照。

## 4. 规则

所有数值都是草案，最终由模拟定（§5.3）。

**布局改了两处**（2026-11-02，美术计划 §7，灰盒工具已重跑）：

- **马道 `M`**：每面墙两条，在城门两侧，紧贴墙的内侧，每条 3 格长。低端在门内的路旁，向外升到墙顶：北墙 x 20–22、25–27（y 5），南墙同样的 x（y 15），西墙 x 15、东墙 x 32 的 y 6–8 和 y 11–13。
- **部署区**（只是界面高亮，不进画面）：
  - 蜀军：y 21–25 的空地（工棚除外），加木栅以内的空地。开局都在墙头弓兵射程以外。
  - 魏军：城墙走道、门楼顶和城内的空地。

### 4.2 部队

- **蜀军**：10 支。本阵（诸葛亮，亲兵约 1,000）加 9 支，每支 1,500–3,000 人，合计约两万。兵种只有步兵和弓弩兵；姜维在野战里是骑兵，攻城战里改领步兵。武将：魏延、姜维、王平、吴懿、廖化等，属性取现有名录。
- **魏军**：6 支，每支 150–300 人，合计约 1,300。郝昭本队加 5 支，兵种是步兵和弓兵。郝昭、王生（副将；《资治通鉴》载曹真派郝昭、王生守陈仓）是新增武将，需要新立绘（美术 F02）。
- **器械**不算进 10 支的上限，场上最多 6 件。器械有耐久、没有兵力，自己能移动（推车的人不单独算），不能攻击部队，井阑除外。
- 士气阈值、受伤兵、兵种克制沿用野战的规则，直接复用纯函数。

### 4.3 正面宽度（攻城的核心）

野战里伤害和攻方兵力成正比，两万打一千，一击就能打光。攻城战里，每次攻击计入的兵力有一个上限，叫"正面"：城墙上一次只有那么宽能接战。

```
计入兵力 = min(攻方兵力, 正面)
伤害 = 计入兵力 × 0.3 × 武力比 × 士气 × 兵种克制 × 高度修正 × 掩护修正（野战的其余修正照用）
```

| 交战方式               | 正面（草案） | 修正（草案）                  |
| ---------------------- | ------------ | ----------------------------- |
| 平地近战（城外、城内） | 不设上限     | 同野战                        |
| 弓弩射城头             | 600          | 城头守方有女墙掩护，受伤 ×0.3 |
| 云梯登城：梯上打城头   | 150          | 攻方正在攀爬，反击时受伤 ×1.5 |
| 填平处攀城：墙脚打城头 | 100          | 同上                          |
| 门破后：门洞内近战     | 300          |                               |
| 井阑射城头、城内       | 300          | 高过城墙，**无视女墙掩护**    |
| 守方从城头打城下       | 不设上限     | 居高 ×1.3；弓兵射程 +1        |

效果：蜀军靠人多，能同时在几处施压，轮换受伤部队；魏军靠城墙，以少打多，但处处都要守。

### 4.4 城墙、登城与马道

- 攻方部队登上城墙只有两种方式：
  - 从架好的云梯底下那一格；
  - 从城堑填平后的墙脚格。
- 目标墙格有守军，就先打（上表的正面）；没人，或守军被击退，就可以登上。
- 守方在墙上随意走；城门两侧的墙经门楼顶相连。墙顶和城内地面只经马道相通。攻方登上城墙后，也要走马道才能下到城内。
- 马道整条都贴着墙，但只有高端那一格和墙顶相通，只有低端那一格和地面相通；中间那格只能沿着马道走。
- 墙头部队被打退时，向马道方向退。

### 4.5 城门

- 南门耐久 800，东、西、北门各 500（草案）。只有冲车能有效撞门；部队打门伤害 ×0.1。
- 门楼受损过半，画面换"受损"状态；耐久到 0 时城门破，门洞变成双方都能进的格，守方全军士气 −10。
- MVP 里城墙不会被打塌，只有门会破。

### 4.6 城堑与填堑

- 城堑两行（南墙外 y 17–18）。门前有木桥，冲车只能走桥。
- **填堑**：土车，或没有器械的步兵（效率减半），在城堑边上执行"填堑"。每格要 3 次填满。外侧那一行填平了，才能填内侧那一行。
- 内侧那一行填平的格子就是墙脚，可以直接攀城（正面 100）。

### 4.7 器械

| 器械 | 解锁   | 工期 | 耐久 | 移动 | 作用                                                       |
| ---- | ------ | ---- | ---- | ---- | ---------------------------------------------------------- |
| 云梯 | 第一幕 | 2 日 | 120  | 2    | 停在城堑外沿，"架梯"后连到对面墙格；之后部队可以从梯底登城 |
| 冲车 | 第一幕 | 3 日 | 300  | 2    | 只能走路和桥；在门前每日撞门一次                           |
| 土车 | 第一幕 | 1 日 | 80   | 2    | 每日填堑一次；填 3 次后车用完                              |
| 井阑 | 第二幕 | 4 日 | 250  | 1    | 射程 4，正面 300，无视女墙掩护；能射到城内                 |

- 工棚两座，各一条队列，同时只造一件。造好的器械出现在工棚门口。
- 被毁的器械变成残骸，原地挡路，可以绕开（美术 C07 是 P1，MVP 用"燃烧"状态的残图代替）。

### 4.8 守方反制

| 反制   | 谁能用                               | 效果（草案）                                                    |
| ------ | ------------------------------------ | --------------------------------------------------------------- |
| 火箭   | 弓兵，射程内的云梯、井阑、土车       | 耐久伤害 = 兵力 × 0.4；风天 ×1.25，雪天 ×0.6；点燃后次日再掉 20 |
| 石磨   | 站在门楼顶或紧邻冲车上方墙格的部队   | 冲车耐久 −200；每支部队每两日一次                               |
| 礌石   | 城头的步兵，打正下方梯底或墙脚的部队 | 伤亡 = 兵力 × 0.25，对正在攀城的部队 ×1.5；每支部队每日一次     |
| 筑重墙 | 第二幕起，城内的任一部队             | 站在施工线上执行"筑墙"，每次进度 +1；每段 4 次建成              |

重墙在 y 14，按缺口分成四段：x 15、x 17–22、x 25–30、x 32；缺口在 x 16、x 23–24（路口）、x 31。建成的一段同城墙：守方能站，攻方只能从缺口过。南墙的两条马道落在重墙和南墙之间的口袋里。

### 4.9 军令

- **诸葛亮**每日一道：
  - **鼓舞**：一支部队士气 +15；
  - **督造**：一座工棚进度 +1 日；
  - **轮换**：一支受伤部队回营，次日恢复部分伤兵，当日不能行动。
- **郝昭**每日一道：
  - **鼓舞**；
  - **死守**：一段墙上的守军当日受伤 ×0.7；
  - **夜修**：城门耐久 +100。
- 野战的六种计策在 MVP 里不用。

### 4.10 余粮与援军

- 余粮从 20 日开始，每日日终减 1，到 0 时史实结局。
- 张郃的距离从 22 日开始，每日减 1，只作显示（DM3）。
- MVP 不做口粮多少的选择。

### 4.11 胜负

- **胜**：日终有蜀军部队站在帅府前庭任一格；或魏军全灭、全军溃散。
- **史实结局**：第 20 日日终余粮耗尽；或玩家下令撤军。
- **败**：蜀军全军溃散；或本阵被击溃。
- 每日的顺序：玩家行动 → 结束本日 → 魏军行动 → 器械燃烧、工棚进度、余粮结算 → 下一日。

## 5. AI 与数值

### 5.1 魏军守城 AI

沿用野战 AI 的做法：给每个候选行动打分，取最高分。只是候选行动和打分换成攻城的。优先级大致是：

1. 冲车在门前：石磨。
2. 射程内有云梯、井阑、土车：火箭，先打已经架上的云梯。
3. 有墙格受威胁（梯已架上、墙脚已填平、墙上有蜀军）：就近调兵增援；墙上有蜀军就反击。
4. 受伤部队从受压的墙段退下，换没受伤的上去。
5. 第二幕：抽调不在一线的部队筑重墙，先修正对缺口最多那一段。
6. 门破或重墙失守后：退守帅府前庭，死战。
7. 很少出城。只在冲车或土车孤立在桥头、身边没有蜀军护卫时，才出城突击。

### 5.2 蜀军脚本策略（只给模拟用）

两种对照策略，不给玩家用：

- **合格**：造齐器械，填堑开出两处以上攀城点，几路同时压上，轮换伤兵。
- **蛮攻**：不造器械，全军堆在南门和桥头。

### 5.3 数值目标（模拟 200 局）

| 指标                               | 目标       |
| ---------------------------------- | ---------- |
| "合格"策略胜率                     | 55–75%     |
| "蛮攻"策略胜率                     | ≤ 5%       |
| "合格"策略获胜的平均日数           | 13–18 日   |
| 第一幕结束时，蜀军至少被毁一件器械 | ≥ 80% 的局 |
| 魏军 AI 一个回合用时（本机）       | ≤ 1 秒     |

模拟工具写成 `tools/siege-sim.mjs`，输出胜率、日数分布和每种器械的存活率，做法同现有的战役对照实验。

**2026-11-02 第一轮结果**（`node tools/siege-sim.mjs 200`，Claude 独立重跑，逐局一致）：合格 57% 胜、43% 史实结局、0 败，获胜平均 16.4 日（13–20 日都有）；蛮攻 0% 胜；81.5% 的局第一幕至少被毁一件器械；魏军回合 p95 0.11 秒、最长 0.82 秒。为此改的数：部队打门计入兵力至多 100（仍 ×0.1，§4.5"只有冲车能有效撞门"）；土车耐久 80 → 50、每车三次各填 1.5；步兵填堑仍是 0.5；云梯耐久 120 → 200。冲车撞门 160、火箭 0.4、燃烧 20、礌石 0.25 不变。

两点留给试玩：合格策略的胜局全是从城墙攻进去的，南门从没撞破过（冲车撞满五次前就被石磨砸毁，和史实一致，但冲车这条路在模拟里没有回报）；200 局里只有 57 种不同的对局（开局固定、战斗无随机，差别来自天气和脚本按种子的选择）。

S1 → S2 → S3 → S4 → S5 → S6 → S7。S1 没通过，后面都不开工（美术计划 §10）。S5、S7 和地图上的件不相干，你想换换手的时候可以提前。每件出完放进 `attempts/`，我在预览页里摆到图上看对位和风格，你确认后再出下一件。

## 9. 代码结构

```
src/siege/
  content/   陈仓的布局、几何、部队编成、武将、剧情文本键
  rules/     状态与类型、地图与高度、移动（城墙、云梯、马道）、正面宽度与伤害、
             城门、城堑、重墙、器械与工棚、军令、日结算、胜负
  ai/        魏军守城 AI；蜀军脚本策略（只给模拟）
  render/    投影、场景与深度排序、SVG 视图、精灵、特效、点选
  ui/        SiegeApp、开场、战斗、结局、总结；各面板
  save.ts    独立存档位（不和战役存档混）
  i18n/      攻城的中英文本
tests/siege/  规则、AI、渲染几何的单元测试；从开始到结局的端到端测试
tools/siege-sim.mjs  数值模拟
```

- **复用**：v0.3 的界面组件、语言切换、武将立绘、视口和平移缩放、士气与经验的纯函数、确定性随机数的做法。
- **入口**：开始画面加一张卡，点开进 `SiegeApp`；开发时 `?siege-preview` 打开预览页（美术计划 §11）。
- **不改**：野战规则、战役、存档格式。v0.4 的修复需要时合进本分支；本分支尽量不碰 v0.4 的文件，以免冲突。
- **状态**：同野战，纯 JSON、确定性；一局的随机数种子存在存档里，读档后同样的操作得到同样的结果。

## 11. MVP 验收

- [ ] 中英文本完整，没有漏译。

## 12. 风险与对策

| 风险                   | 对策                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 正面宽度规则不直观     | 预测里写明修正；第一次登城时弹提示；城防面板标出哪里是突破口                       |
| 二十日太长、中段重复   | 第二幕换器械、魏军筑重墙，让局势变；轮换和军令给每日新的选择；试玩后可以缩到 15 日 |
| 守城 AI 太死板或太聪明 | 打分可调；用两种脚本策略对照；看试玩录像调                                         |
| 2.5D 点选不准          | 顶面多边形和画面用同一套投影；三档缩放下写自动测试                                 |
| 美术跟不上             | 美术优先：每批的出图材料提前备好，你出图不用等我；预览页里随时看到已入库的件       |
| SVG 性能不够           | 精灵数有上限（约 200）；特效粒子数有上限；必要时换 Canvas，渲染接口不变            |
| 和 v0.4 分叉太久       | 本分支不改 v0.4 文件，只加入口；需要时合入 v0.4                                    |

## 看什么

- 和 S1-02 标准件、S1-01 v2-a 是不是同一套笔法、颜色和光照。
- 每件都在自己的框里，底边落在灰盒的地面框上；背景纯品红，没有地面、雪地和落地影子。
- 吊架的臂朝南伸出；不画绳子和石磨。
- 石磨是平放的厚圆盘。
- 把图缩到一半（游戏 100% 的大小）看：放在 S1-01 的雪地上不突兀。

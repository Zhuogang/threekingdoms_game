## 5. 已经定的事

**美术（DS1–DS9，2026-11-01）**：正面斜俯视，每格 64×48、每层 24px；攻方在南，城在北；西南低阳；**DS5 定 α 整画切层**（在预览页对比 β 后定）；风格 A 界画淡彩；冬雪；部队沿用 ink-04 的 1 人 / 3 人规则；军色拉开明度（蜀青绿 `#5f9a5a`，魏深靛 `#2f4a6e`）。

**α 的意思**：城池是一整张画，按灰盒蒙版切层；会变的部分（城门受损和门破、填堑、重墙、起火）在整画上局部重画成补丁；营地、器械、部队、野外点缀才出分件，S1-02 是它们的风格标准件。

**MVP（DM1–DM10，2026-11-01）**：只做蜀攻；一场连续的二十日战斗，分两幕；余粮 20 日是硬时限，张郃只显示距离；日终占帅府前庭即胜；独立的 `src/siege/` 规则；SVG 渲染；**美术优先**；开场纯叙事、可跳过；中英双语；诸葛亮作本阵上场。地道、扮演魏军、骑兵追击放到 v0.2。

**2026-11-02 备 S2 时定的**：

- S1-01 v2-a 直接当城池本体，放在全图的 (768, 48)，不重画。
- 全图 3072×1536，原点在西北角，四边由程序淡出成纸色，不画远山。
- 以 v2-a 为中心分五块扩画，每块 1536×1024，顺序西北、东北、南、西南、东南；每块在已画好的一侧留 48px 渐变，拼之前在 ±8px 内对齐。
- 整画里只画地面；地道口先画成雪地。
- 马道：每面墙两条，在城门两侧，紧贴墙内侧，每条 3 格，低端在门内的路旁。只有高端那格通墙顶，只有低端那格通地面。
- 部署区（只是界面高亮）：蜀军在 y 21–25 的空地加木栅以内，魏军在墙上和城内。
- 重墙在 y 14，分四段，缺口在 x 16、x 23–24、x 31。

## 6. 工作约定

- **分工**：我写布局、灰盒、提示词、工具和接入；你用另一个 ImageGen 流程出图。每件出 3–4 张，你确认后再做下一件。
- **生成的文件不手改**：`docs/siege/chencang/art/` 下的 README、灰盒、网格、蒙版、`footprints.json`、`steps/`、`steps.json` 都由工具生成。要改就改 `tools/build-siege-blockout.mjs` 再重跑。
- **选定的图记在工具里**：S1 是各资产的 `final` 和 `CHOSEN_VIGNETTE`、`CHOSEN_GATE`；S2-01 是 `MAP_PICKS`。
- **出图工作区**：仓库根目录的 `attempts/` 是 ImageGen 流程的工作区（原始 PNG、对比图、manifest），不能删。各资产文件夹里的 `attempts/` 放正式出图。
- **提交和推送**都等你说了再做。
- **范围**：本分支尽量不碰 v0.4 的文件，只动入口和开发开关；野战图保持纯 2D。
- **语言**：文档用中文；聊天跟你最近一条消息的语言。

## 7. 常用命令

```bash
node tools/build-siege-blockout.mjs   # 重新生成全部灰盒、蒙版、提示词和索引（约 25 秒）
node tools/compose-siege-map.mjs      # 拼 S2-01，写出下一步的输入和拼图进度（要装 Chrome）
npm run dev                           # 然后打开 http://127.0.0.1:5173/?siege-preview
npx vitest run tests/siege            # 攻城的单元测试，现在 13 个
npx prettier --check docs/siege tools/build-siege-blockout.mjs tools/compose-siege-map.mjs
```

S2-01 的一步：上传 `inputs/<步>.png` 出图 → 存成 `attempts/<步>-v1.webp`… → 选定后把文件名填进 `MAP_PICKS` → 先跑 `build-siege-blockout.mjs`，再跑 `compose-siege-map.mjs` → 看终端报的偏移和差值，看 `preview.webp` 的接缝 → 得到下一步的 `inputs/`。偏移超过 ±4px 或差值明显偏大，就重出那一块。

## 10. 换机器

- **代码**：分支已在 GitHub（`Zhuogang/threekingdoms_game` 的 `siege_v0.1`）。新机器上 `git fetch`，再 `git checkout siege_v0.1`。
- **依赖**：`npm install`；装 Google Chrome，`compose-siege-map.mjs` 和野战的出图工具都用 Playwright 的 `chrome` 通道。
- **我的记忆笔记不跟仓库走**：它们在本机的 `~/.claude/projects/<仓库路径>/memory/`。和陈仓有关的内容这一页都写进来了，新机器上的会话先读这一页。
- **这台 Windows 笔记本特有的**（换了机器可能都不适用）：
  - git 不在 PATH 上，用 GitHub Desktop 自带的 `%LOCALAPPDATA%\GitHubDesktop\app-*\resources\app\git\cmd\git.exe`；
  - PowerShell 5.1 写文件会带 BOM，所以提交说明要写进不带 BOM 的文件，再用 `-F` 传进去；
  - 有些写法会写出 CRLF 换行，prettier 会报，跑一下 `npx prettier --write` 就好；
  - 野战 50ms 的性能门槛在这台机器上本来就过不了。

资产文件夹都在 [`docs/siege/chencang/art/`](chencang/art/README.md)，每件的 `README.md` 是出图时的权威提示词，`generation-manifest.json` 记着选定的图和怎么切；游戏用各文件夹的 `runtime/`、`poses-game/`、`icons/`、`pieces/`。

- **S1** 风格锁定 6 件；**S2** 全图整画（S2-01 分六步）加营地、木栅、工棚、野外点缀；**S3** 城门受损/门破、填堑、重墙的补丁（`tools/compose-siege-states.mjs` 生成）；**S4** 器械与反制；**S5** 部队、旗帜、武将和立绘；**S6** 特效、图标、纸纹；**S7** 主视觉、开场、结局插画。
- 出图用 Codex 内置的图像生成（`gpt-6.1-sol`，`xhigh`）；分件表以 2 倍尺寸画在品红底上，再抠图（已处理品红和中性墨边的色边）。

## 5. 已经定的事

**美术（DS1–DS9，2026-11-01）**：正面斜俯视，每格 64×48、每层 24px；攻方在南，城在北；西南低阳；**DS5 定 α 整画切层**（在预览页对比 β 后定）；风格 A 界画淡彩；冬雪；部队沿用 ink-04 的 1 人 / 3 人规则；军色拉开明度（蜀青绿 `#5f9a5a`，魏深靛 `#2f4a6e`）。

**α 的意思**：城池是一整张画，按灰盒蒙版切层；会变的部分（城门受损和门破、填堑、重墙、起火）在整画上局部重画成补丁；营地、器械、部队、野外点缀才出分件，S1-02 是它们的风格标准件。

**MVP（DM1–DM10，2026-11-01）**：只做蜀攻；一场连续的二十日战斗，分两幕；余粮 20 日是硬时限，张郃只显示距离；日终占帅府前庭即胜；独立的 `src/siege/` 规则；SVG 渲染；**美术优先**；开场纯叙事、可跳过；中英双语；诸葛亮作本阵上场。地道、扮演魏军、骑兵追击放到 v0.2。

**布局（2026-11-02）**：全图 3072×1536；马道每面墙两条、在城门两侧；部署区蜀军在 y 21–25 加木栅以内；重墙在 y 14，分四段，缺口在 x 16、x 23–24、x 31。

**数值要点**（任务 D、E 调过，以 `src/siege/rules/` 为准）：正面上限——城上齐射 600（女墙 ×0.3）、云梯 150、墙脚 100、破门 300、井阑 300；部队打城门最多算 100 人、×0.1；填堑一格要 3，土车每载 1.5、每车 3 载，步兵每次 0.5；工期云梯 2 日、冲车 3 日、土车 1 日、井阑 4 日（第二幕起）；冲车每次撞门 −160，南门 800；新局种子 228。

## 10. 换机器

- **代码**：分支在 GitHub（`Zhuogang/threekingdoms_game` 的 `siege_v0.1`）。新机器上 `git fetch`，再 `git checkout siege_v0.1`；`npm install`。
- **我的记忆笔记不跟仓库走**：它们在本机的 `~/.claude/projects/<仓库路径>/memory/`。和陈仓有关的内容这一页都写进来了，新机器上的会话先读这一页。
- **Windows 笔记本**：git 用 GitHub Desktop 自带的；PowerShell 5.1 写文件带 BOM，提交说明写进不带 BOM 的文件再 `-F`；CRLF 会让 prettier 报错，跑 `npx prettier --write`；野战 50ms 性能门槛过不了。
- **WSL（Ubuntu）**：node 在 `~/.local/node/bin`；Chromium 要 `LD_LIBRARY_PATH=~/.local/chromelibs/usr/lib/x86_64-linux-gnu`，Playwright 用 `channel: undefined`；Windows 的浏览器要用 WSL 的 IP 访问开发服务器（`vite --host 0.0.0.0`），不能用 localhost。

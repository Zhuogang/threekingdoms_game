Original imagined historical depictions created for this project with the built-in image_gen tool. These are artistic interpretations, not authenticated contemporary likenesses. No commercial game portraits or third-party portrait scans were reused.

Created October 19, 2026 with OpenAI's built-in image_gen tool; the tool did not expose a model identifier. All portraits were commissioned through original project prompts, with no reference image input. Names identify imagined depictions, not authenticated likenesses. No public-domain historical image or commercial game portrait is claimed as a source. Generated-output use is subject to the applicable creation-service terms; no third-party image license is invented here.

The complete art direction and per-person briefs are in [the prompt set](../../tools/portrait-spec.json). Runtime provenance, individual prompts, generated-source filenames, dimensions, byte counts, and SHA256 checksums are in [the bundled manifest](../../public/assets/portraits/credits.json). Only resize and WebP compression were applied to the generated originals. Original generated PNGs remain in the tool's output directory; the project contains the final local delivery renditions.

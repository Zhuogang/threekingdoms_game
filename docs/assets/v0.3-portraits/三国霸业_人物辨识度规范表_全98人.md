# 三国霸业：人物辨识度规范表（全 98 人）

用途：统一所有人物立绘的辨识度规则，避免“全员英俊化”“文臣脸模板化”“同阵营撞脸”。

## 全局规范

1. **一人一标志**：每人至少有一个不可替代的视觉钩子（如羽扇纶巾、白眉、白马将军、伤疤、长髯、道教帽、帝王冠等）。
2. **控制英俊比例**：只有少数人物走清俊路线（如郭嘉、周瑜、陆逊、姜维、关平、马良、曹丕等）。
3. **文臣分型**：清俊名士型 / 智慧军师型 / 温厚重臣型 / 士族名流型 分开处理。
4. **武将分型**：豪勇型 / 宿将型 / 边疆型 / 贵族型 / 刚猛保镖型 分开处理。
5. **同阵营也要分层**：不要让同阵营人物只靠颜色区分，要用年龄、脸型、胡须、身份物件、服饰层级来拆开。

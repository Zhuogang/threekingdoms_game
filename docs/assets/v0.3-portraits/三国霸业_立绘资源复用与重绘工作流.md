# 三国霸业：立绘资源复用与重绘工作流

## 核心原则：学会重新用已有的资源

不要每次从零生成。对于已经接近可用的图，应优先把现有图片作为参考图或编辑底图，只修复最影响辨识度的问题。

## 推荐工作流

1. **先审查**：先看 45 人 contact sheet，标记撞脸、过英俊、道具缺失、年龄错误。
2. **分层返工**：
   - A 类：直接可用，不动。
   - B 类：小修（如郭嘉手势、马良白眉、周泰伤疤）。
   - C 类：中修（如孙权、诸葛瑾、蒋琬、孔融）。
   - D 类：重构（如诸葛亮、庞统）。
3. **引用旧图**：返工时把当前图作为参考图，确保风格不漂。
4. **先做人设锚点**：诸葛亮、庞统、孙权修对了，整套风格会稳定很多。
5. **最终入库**：只有独立高清图通过后，再统一裁切导出 256×256 WebP。

# 武将扩容整体复核

2026-10-26。复核范围覆盖 R1–R5 的登场、生卒、开局势力与局内归属、搜索编兵、头像资料、存档以及伤兵与战斗衔接。修复与自动化复核已完成。此前 [R5 证据](../officer-roster-r5-2026-10-26/README.md)保留原样。

## 发现与修复

| 问题                                                                       | 修复及回归                                                                                                                                     |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 战中资料页仍读战前兵力，受伤甚至被击溃后仍显示原健康兵与零伤兵             | 改为只读当前战场单位；合编时标明编队总数与战后比例分配，避免将整队归给一名武将。驻城、行军及被俘继续读取当前所部记录，不提前修改结算数据       |
| 存档可以把固定骑兵将变成弓兵，也接受已故记录带兵或带伤兵                   | 名册校验绑定人物基础兵种，并拒绝已故记录的非零兵员；正常归属变化、活人纯伤兵仍可存取                                                           |
| 资料没有说明为何公孙瓒等以在野身份存在；有争议、推算及玩法年份也未明确标注 | 双语补充开局原势力未建模的说明，与本局当前所属分开；190 年甘宁、刘表不套用后来的关系。生卒显示推算／争议／游戏参考，登场显示游戏参考或玩法近似 |
| 成年报告固定声称武力 +3、智力 +2，即使能力已到上限                         | 报告使用实际增量，覆盖装备武力 104→105、105→105 及智力 100 的边界，训练和装备收益保持                                                          |

旧测试中曾把颜良改成步兵、把十二个不同兵种的人全部改成步兵，或人为改袁绍兵种。现在改用实际兵种匹配的名册人物，保留兵员、经验、合编上限、NPC 出征及保存断言。NPC 月结粮耗断言也改为核对自治编兵前实际支付口粮的预备兵库存，不能用已转入新部队后的库存倒算先前粮耗；未放宽粮食精确比较。

登场、生卒与归属主流程的复核结果：两个开局仍为 69 条在世记录／81 条记录（66 在世、15 已故）；未来人物不提前进入搜索池，年界只出现一次，已故记录保留；局内不按参考卒年死亡，也不按史实后续投奔强制转属。新人物仍零兵加入，编兵只用同兵种、合法可用库存，伤兵和整编限制保持。原 53 人头像、45 人新头像、复姓缺图回退及楼船展示名单保持。此次没有重定历史生卒年、登场年或扩大势力数量。

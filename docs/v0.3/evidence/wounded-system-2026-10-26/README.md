收尾新增粮账回归：当日战场已付口粮随“所部→普通预备兵／留城伤兵→另一所部”实际转移，存读档后仍保留；无主将民兵及其新伤兵战后留城也不重复计费，次日正常恢复城市供粮责任。遣散清理空余额，失城清理原预备兵信用，避免把已离开军事编制的人的当日记录交给新兵。退路排序同步使用随军实际兵种、伤兵与下一日出发 ETA。

既有回归随规则调整：删掉测试对“空城免费 500 民兵”的依赖，需要战斗的场景提供真实守军；月度孤立场景明确普通预备兵库存，避免新粮耗改变测试前提；释放交换改断言实际行程。修复了地图按钮 SVG 包围框中心落在空白／邻城上的真实点击问题：可访问按钮落在顶层地理锚点，并保留图画和标签点击，不使用强制点击绕过。

## 可导入的短场景

先导出当前战役，再从战役菜单导入其中一个 JSON。文件是受控验收场景：以固定人数、经验和随机种子建立，去程各段被缩短以快速开战；战后返程使用实际路线。并非正常新局难度或随机胜率样本。[机器核对结果](scenario-checks.json)。

| 存档                                                   | 已核对的状态                                                                          | 建议实际操作与观察                                                                                 |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [弱方保留精锐](weak-force-saving-elite.json)           | 5000 精骑被击溃后保留 3000 伤兵、1240 XP；友军掩护有序撤退，已有真实返程。            | 确认战报，回城、养伤，再次出征；观察等待时长是否可接受、旧伤兵是否明确留城、精锐是否仍有再战价值。 |
| [俘获精锐后的整编](captured-elite-reorganization.json) | 袁绍视角；曹操所部独立被俘后招降成功，4000 可战／600 伤兵保留经验，整编剩余 10 日。   | 查看粮耗及整编，不应立即参战；推进有效驻城日，查看恢复与解锁；观察胜方负担和滚雪球收益。           |
| [多将撤退前](multi-officer-withdrawal.json)            | 曹操、夏侯惇参战，接战后每将 5%，至少一将 9.75%；固定种子确认后曹操被俘、夏侯惇返程。 | 打开并取消撤退，再确认；核对提示、部分被俘的可理解性、返程人员及读档后结果。                       |

以上短场景已通过真实命令和存档检查；浏览器自动化验证了恢复、处置和撤退操作。**尚未执行长期人工平衡试玩**，不把自动化断言写成人类对“愿不愿撤、养伤是否太久、招降是否过强”的结论。10%/5%/25%/10 日等参数保持计划默认值；实际反馈应记录场景、日期、人数、粮食和具体操作，再决定是否调参。

另对三个存档执行了[每日命令短回放](scenario-replays.json)，每推进一天都重新编码、解码并核对状态：

- 弱方场景经过 14 个推进日返城，到达当天不治疗；随后 22 个完整有粮驻城日恢复至 **2709 可战、291 伤兵、1240 平均经验**。返回的 3000 人没有变成新兵或立即满编。
- 招降场景推进 **11 个日历日，含招降当天不计进度的一日** 后完成 10 个有效整编日；剩余 **4393 可战、207 伤兵、1240 平均经验**，合计仍为 4600。
- 多将场景预览不抽签；确认并重载后，曹操 **4000 可战／600 伤兵被俘**，夏侯惇 **2000 人独立返程**。至少一将被俘的界面概率为 9.75%，不按同编队连坐。

回放中的其他战场如有需要使用既有托管入口；没有改写治疗比例、跳过驻城资格或补满粮食。这些是机器可复现的过程观察，人工对节奏和公平感的判断仍待执行。

## 兼容性与剩余验收

外层仍为 v0.3 存档，新增 `personnelSchema: 1`。本功能之前的旧存档不兼容且不迁移；开始页提供原文导出，新开取消不会覆盖原档。工作区中原有地域城池和其他美术文件未纳入本次功能修改。

剩余人工验收：三组场景的真实玩家判断、长期战役胜负与招降平衡，以及既有真实低端机检查。当前结果支持本地试玩候选版，不构成上述人工验收完成证明。

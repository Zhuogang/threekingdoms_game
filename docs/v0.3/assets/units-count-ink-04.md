# 1 人／3 人图标：人物尺寸固定

2026-10-26，按后续反馈取代陆上 3 人／5 人图标。

- 少于 500 人显示 1 个代表人物，500 人及以上显示 3 个；六种陆地外观均适用。
- 每组复用同一张单兵底图。单兵只缩放一次，1 人和 3 人版本使用相同的 512×512 画布和单兵像素尺寸，不再分别把整队撑满图标。
- 1 人版的前景人物保留在三人版的相同位置，只增加两名后排人物。这样切换不会使原人物缩小或移位。
- 骑兵的一名人物包含骑手与马匹。两种船只沿用 ink-03；兵种、Lv.11 进阶、500 人分档及每格占位没有规则调整。

## 图片与复现

六张单兵底图由内置 `image_gen` 编辑对应 ink-03 小队图，保留笔触、颜色和装备，移除其余人物并补全遮挡。随后机械复制同一单兵，以固定比例打包十二张陆上运行图。

运行图位于 `public/assets/v03/units/*-ink-04.webp`；水上仍使用 `*-ink-03.webp`。在仓库根目录运行 `node tools/prepare-unit-icons.mjs`、`node tools/unit-icons-contact.mjs` 可重建；需要 `sharp` 和 `@napi-rs/canvas`，也可用 `HEGEMONY_IMAGE_NODE_MODULES` 指向工作区依赖。

## 验证

回归检查六组配对图的单兵来源、尺寸、哈希和前景位置一致。浏览器进一步解码真实 WebP，比较两档中前景人物的全部不透明像素，确认没有缩放或移位，并确认三人图增加了新的可见人物区域。阈值切换、上下水与缺图回退继续检查。

59 项渲染检查、本轮 14 个浏览器用例及构建通过。浏览器像素用例最初要求至少 1000 个完全不透明像素，但水墨步兵仅有 935 个；改为要求样本非空且全部匹配后单独重跑通过，六组人物的匹配像素差异均为零。40/56/112px 对比及实际战场截图已复核。结果同步记录在[实施进度](../implementation-status.md)。

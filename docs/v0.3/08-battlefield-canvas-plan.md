## 0. 摘要

- 作战界面改成**纯 2D 俯视的大幕布**：48×32 格，每格 64px，整张 3072×2048，可以拖动和缩放。
- 单位改成**武将头像 + 兵种徽记**。
- 战场按**进攻方走的最后一段路线**从 10 种地形里选，另有 5 个按进攻方向的特例。
- **战斗规则一条都不改**。不过新美术要能用上，渲染、地图数据和存档校验必须跟着改，范围见 §1。

## 2. 决策变更

| ID  | 原来                                 | 改为                                                                           |
| --- | ------------------------------------ | ------------------------------------------------------------------------------ |
| D3  | 24×20 场地，480 格，四个地域样板     | **48×32，1536 格，10 种地形战场（含变体），按最后一段路线选图**                |
| D4  | 高视角斜俯视水墨画面，React/SVG 投影 | **纯 2D 正俯视大幕布：水墨淡彩手绘背景，上面叠网格**；不复制任何三国志系列素材 |

D9（存档信封仍是 v3，旧战斗记录继续可读）、D10（不攻城，所有兵种都能下水）、D11（超时按存活兵力判，平局守方胜）都保持不变。

新增约定：

- **B1　攻左守右**：攻方一律从左侧入场，守方在右侧。画面不再按进攻方向旋转。
- **B2　一路一图**：同一条路线、同一个进攻方向，每次打都是同一张图。随机种子不再改动地形；每一仗的变化来自兵力、天气和部署。
- **B3　五种格子**：规则只认平原、森林、丘陵、水、峭壁五种格子。画面上的元素按 §5 归入其中一类，不新增格子类型。
- **B4　渡河宽度**：需要横渡的水面，主要渡河点上连续的水不超过 3 格。更宽的江河，中间放沙洲或江心洲当落脚点。理由：涉水每步至少花 2 点移动，步兵、弓兵、护卫一天只能走 1 格水。

## 3. 幕布与网格

| 项目       | 现在                     | 新方案                                                                    |
| ---------- | ------------------------ | ------------------------------------------------------------------------- |
| 网格       | 24×20 = 480 格           | **48×32 = 1536 格**（约 3.2 倍）                                          |
| 格子       | 128×64 菱形              | **64×64 正方形**                                                          |
| 幕布       | 约 3096×1688（等距投影） | **3072×2048**（3:2）                                                      |
| 缩放       | 适配全图到 5 倍          | 每格在屏幕上 32–96px；100% 时每格 64px；32px 时全图约 1536×1024，一屏看全 |
| 一屏能看到 | 全图                     | 1080p 去掉侧栏后约 22×13 格，大约是全图的 1/5                             |

选 48×32 的理由：3:2 和常用的出图尺寸 1536×1024 一致。出图后放大 2 倍，每格正好从 32px 变成 64px，格子能对齐。

**坐标**：x 0–47 从左到右，y 0–31 从上到下。

**区域划分**

| 区域     | x 范围 | 用途                                             |
| -------- | ------ | ------------------------------------------------ |
| 攻方后方 | 0–7    | 攻方营地（约 x 5）、来路、背景                   |
| 主战场   | 8–39   | 双方部署和交战。地形特色集中在这里，约占全图 2/3 |
| 守方后方 | 40–47  | 守方营地（约 x 42）、城池一角或关后的道路        |

- **部署区**：攻方 x 10–13，守方 x 34–37，y 大致居中，按地形调整。每方至少 10 格，不能放在水或峭壁上。
- **节奏**：两军前线相距约 21 格（现在约 17 格）。双方相向推进时，步兵大约 3–4 天接敌（现在中位数是 2 天）。
- **细节层级**：每格在屏幕上小于 44px 时，单位只显示势力色圆片和兵种字；44px 及以上才显示头像。
- **网格线**：淡墨细线，默认显示，可以关掉。
- **操作**：保留现有操作，包括"全图 / 部队 / 营地"三个镜头按钮、小地图跳转、方向键移动光标、Shift+方向键平移、+/- 缩放、Home 看全图。新增鼠标拖动平移和滚轮缩放。

## 4. 单位底牌

- **头像**：圆形底牌，100% 缩放时直径约 56px。
- **兵种徽记**：左下角小圆章，分步、骑、弓、水、锐、卫六种，对应六个兵种（沿用 `troopGlyph`）。
- **势力色**：头像外圈描边，加右上角小旗。
- **兵力条**：底牌下方的细条。
- **编队**：显示一位武将的头像，右下角加人数角标，比如"×3"。
- **在水上**：底牌下加船形底座，替换现在的 transport-craft 精灵。
- **状态**：
  - 选中：高亮外圈。
  - 可攻击目标：红圈。
  - 已行动：变灰。
  - 混乱、鼓舞：右上角小图标。
  - 溃败：半透明。

**头像来源**

- 战斗记录里已经有"编队 → 武将"的对应关系。
- 底牌显示编队里等级最高的武将，同级比武力，再比 ID。这只影响画面，不改编队规则。
- 头像文件是 `public/assets/portraits/<portraitKey>-small.webp`，现有 54 张。高分屏下如果 small 版不够清晰，就改用完整版。
- 民兵或缺头像的部队，用兵种剪影代替头像。

## 5. 画面元素 → 逻辑地形

| 画面元素                                                               | 逻辑格 | 说明                                                |
| ---------------------------------------------------------------------- | ------ | --------------------------------------------------- |
| 田地、草地、土路、驿道、干河床、沙洲、河滩、桥、栈道、城门洞、渡口码头 | 平原   | 栈道和桥只是画出来的，逻辑上是普通平地              |
| 树林、竹林、桑林、芦苇荡                                               | 森林   | 芦苇算森林：可以伏兵，火攻 ×1.4，正好对应"火烧芦苇" |
| 木栅、鹿角                                                             | 森林   | 能穿过但走得慢，火攻 ×1.4，对应"火烧营栅"           |
| 丘陵、土岗、台塬、坡地、大堤、圩堤                                     | 丘陵   | 大堤算丘陵：有防御加成，也能在上面用落石            |
| 江、河、湖、塘、深沼、运河                                             | 水     | 浅滩和沼泽也暂时算水                                |
| 悬崖、绝壁、深谷、关墙、城墙（夯土、砖石）                             | 峭壁   | 不可进入；城门是墙上留出的平原格，关不上            |

**墙和门的规矩**（规则里没有攻城，墙打不破，所以靠布局保证墙后不变成死角）：

- 夯土墙、砖石墙只画 1 格厚。攻击距离只算格数、不看视线，1 格厚的墙弓兵（射程 3）和计策（射程 2–3）都能隔墙打到。
- 每块被墙围起来的地方至少开两个门。一格只能站一支部队，只有一个门的话，守方一支部队站在门上，近战就再也进不去。连在一起的门格算一个门。
- 地图上不能有完全封死、谁也到不了的空地。
- 以上三条由 `tools/build-battlefield-art.mjs` 的校验自动检查。

**画风**（2026-10-23 定稿）：正俯视、光从左上方来的淡彩工笔地图画风，以 ① v4 为样板。固定段就是 `tools/build-battlefield-art.mjs` 里的 `STYLE`、`SHAPES`、`WALLS`、`READABILITY` 四段，每张图的提示词都由这四段加本图的图例和设定组成。改画风只改这四段，然后重新生成全部提示词。

## 6. 十种战场

每一节"格子比例"是给布局用的大致目标，允许 ±5% 浮动。每张图逐格的布局、参考图和提示词在 [battlefield-art/](battlefield-art/README.md)，以那里为准。

### ① 北方旷野

- **原型**：河北平原和鲁北平原，即北平、平原、邺、北海之间。汉末这里土地开阔，故河道、干河床多，村落稀疏。191–192 年的界桥之战（公孙瓒的白马义从对袁绍）就发生在这样的平原上。
- **画面**：以土黄、灰褐为主。方块状的冬麦田和田埂，几条交叉的土路，零星的土坯院墙村落，成排的杨柳，一条小河（如漳水）。远处看不到山。
- **布局**：
  - 主战场大面积开阔。
  - 一条 1 格宽的小河，从上到下在 x 24–27 之间弯曲流过，中段有一座木桥（界桥的意象）。
  - 右上是开放的村落，房舍间只有几棵树；左下是带护城壕的坞堡，东门朝大路、北门朝田野，各有一座小桥过壕。
  - 散布六处低土岗、一道土梁、一条干河床和几片独立的小树林。
- **格子比例**：平原 82%、森林 8%、丘陵 6%、水 4%、峭壁 0。
- **打法**：骑兵的主场。几乎没有遮挡，正面会战。小河 1 格宽，哪里都能涉过，但桥上过河最快。
- **素材**：麦田地表、土路、村落、杨柳林、木桥、土岗。
- **路线**：北海—平原、北平—平原、北平—邺、平原—邺（4 条）。

### ② 中原沃野

- **原型**：黄淮平原，即陈留、许昌、濮阳一带，以及寿春以北。汉末这里人口最密，鸿沟、汴渠、颍水、睢水等人工和天然河道交织。200 年官渡之战，曹操和袁绍就在鸿沟—官渡一带筑营对峙。
- **画面**：比 ① 更绿，田块更细碎。有笔直的沟渠和土堤、驿道、密集的村庄、桑林和榆树林带，守方营地附近有营垒木栅。
- **布局**：
  - 一条 2 格宽的运河，从左上（约 x 16，y 0）斜穿到右下（约 x 32，y 31）。运河上有两座桥，大约在 y 8 和 y 23。
  - 运河两岸各有一道 1 格宽的土堤（丘陵）。
  - 另有 3–4 条 1 格宽的沟渠，横向把田地切成方块。
- **格子比例**：平原 67%、森林 12%、丘陵 8%、水 13%、峭壁 0。
- **打法**：沟渠和土堤把战场分成几块，骑兵要走桥，守在堤上有加成。适合筑营对峙和侧翼迂回。
- **素材**：沟渠、土堤、木桥、村庄、桑林、营垒木栅。
- **路线**：陈留—濮阳、陈留—许昌、陈留—寿春、许昌—寿春、濮阳—下邳（5 条）。

### ③ 黄河津渡

- **原型**：白马津和黎阳之间（濮阳—邺），孟津（洛阳—邺），东汉黄河下游（平原—濮阳，具体河道待核）。200 年的白马之围、延津之战都在这一段。
- **画面**：浑黄的大河，泥沙色水面带漩涡纹。河中有沙洲，两岸是大堤，岸边有渡口码头、渡船和木栈桥。攻方岸是黄土平地，守方岸是台地。
- **布局**：
  - 黄河竖着贯穿 x 20–27，共 8 格宽。
  - 中间 x 23–24 有 3 块沙洲，沙洲两侧各 3 格水，符合 B4。
  - 两岸各有一道大堤：x 18–19 和 x 28–29，都是丘陵。大堤在渡口处断开。
  - 渡口码头两处，大约在 y 8 和 y 24。
- **格子比例**：平原 55%、水 25%、丘陵 12%、森林 8%（岸柳、少量芦苇）、峭壁 0。
- **打法**：攻方必须渡河。人在水里受到的伤害 ×1.25，正好体现"半渡而击"。沙洲是渡河时的跳板，守方要死守渡口和大堤。
- **素材**：黄河水面（可平铺）、沙洲、大堤、渡口码头、渡船、岸柳。
- **路线**：濮阳—邺、洛阳—邺、平原—濮阳（3 条），外加特例：从晋阳攻洛阳。

### ④ 水网泽国

- **原型**：淮河—泗水下游（寿春、下邳），太湖平原（建业—吴）。
  - 寿春北面临淮水，南边有芍陂（大型蓄水陂塘），西北有八公山。
  - 下邳被泗水、沂水环绕。198 年曹操掘开泗水、沂水灌城，擒了吕布。
- **画面**：大量弯曲的河汊、湖塘、芦苇荡，被圩堤围起来的田，小石桥和木桥，水乡村舍。
- **布局**：
  - 没有一条主河，而是 3–4 条 1–2 格宽的水道交错成网，再加 2–3 个湖塘（最大约 5×4）。
  - 陆地被切成 5–7 块，靠桥和圩堤连接。
  - 守方营地建在一块四面环水的高地上，只有两座桥通进去，呼应下邳和寿春。
- **格子比例**：平原 45%、水 30%、森林 15%（芦苇、竹林）、丘陵 10%（圩堤、小丘）、峭壁 0。
- **打法**：骑兵最吃亏的一张图，步兵、弓兵、水军占优。芦苇可以火攻。
- **变体**：
  - **④北（淮泗）**：黄绿色调，偏芦苇和沼泽。第一轮先做。
  - **④南（江南）**：青绿色调，稻田、竹林、乌篷船。第二轮做；做好之前先用 ④北。
- **素材**：河汊水面、湖塘、芦苇荡、圩田（北）或稻田（南）、石桥、木桥、水乡村舍、乌篷船（南）。
- **路线**：寿春—下邳、建业—下邳（④北），建业—吴（④南）（共 3 条），外加特例：攻寿春、攻下邳。

### ⑤ 大江

- **原型**：长江中下游，柴桑、江夏、江陵、建业沿线。
  - 208 年赤壁之战发生在江陵和江夏之间，赤壁与乌林隔江相对。
  - 濡须口（建业—寿春方向）是孙曹多次交战的地方。
- **画面**：青灰、青绿的宽阔江面，有浪纹和流向。江心洲、芦苇荡、两岸滩涂，临江石壁（赤壁意象），水寨（木栅、楼船泊位），楼船和斗舰。
- **两种布局**：
  - **⑤A 沿江**：这几条路线在数据里是"沿江岸路"，不是航道，所以大军沿江行军，江在地图一侧。
    - 长江横贯地图上方 y 0–11，不需要横渡。
    - 可战斗的是下方的江岸带 y 12–31：y 12–14 是滩涂和芦苇，y 26–31 是岸上丘陵。
    - 水军可以从江上包抄侧翼。
    - 守方一侧（x 38–47，y 9–16）有临江石壁和水寨。
  - **⑤B 渡江**：用于从北面攻建业，以及建业—寿春的两个方向。
    - 长江竖着贯穿 x 19–28。中间 x 22–25 是长条江心洲（y 6–25），两侧各 3 格水，符合 B4。
    - 江心洲的上下两端以外是整段宽水，不作渡河点。
    - 守方岸 x 29–31 是临江悬崖，只留两处 3 格宽的登陆滩口，大约在 y 7–9 和 y 22–24。悬崖后面是水寨和营地。
    - 攻方岸 x 14–18 是滩涂和芦苇荡。
- **格子比例**：
  - ⑤A：水 38%、平原 35%、森林 12%、丘陵 8%、峭壁 7%。
  - ⑤B：水 25%、平原 40%、森林 15%、丘陵 10%、峭壁 10%。
- **打法**：在水上打人伤害 ×0.75、挨打伤害 ×1.25，所以守方优势很大。⑤B 的关键是抢下登陆滩口。芦苇荡可以火攻。
- **素材**：长江水面（大面积、可平铺）、江心洲、芦苇荡、滩涂、临江石壁、水寨、楼船和斗舰（作为单位的船形底座）。
- **路线**：
  - ⑤A：柴桑—江陵、柴桑—江夏、柴桑—建业、江陵—江夏。
  - ⑤B：建业—寿春。
  - 共 5 条，外加特例：从下邳攻建业（⑤B）。

### ⑥ 河谷川地

- **原型**：
  - 渭水上游：长安—天水，要翻越陇山。
  - 汉水中游：江夏—襄阳。
  - 白河—汉水：宛城—襄阳。襄阳和樊城隔汉水相望。
- **画面**：一条中等河流穿过狭长的平川，两岸是台地和农田，河谷上下两侧是丘陵和远山。
- **布局**：
  - 上下两条山带：y 0–4 和 y 27–31，由丘陵和峭壁组成。
  - 中间 y 5–26 是可以打仗的川地，宽 22 格。
  - 一条 2–3 格宽的河，呈 S 形从左到右穿过川地，把双方隔在两岸。
  - 过河点：一座桥（约 x 24），另有两处 1 格宽的浅渡。
  - 守方后方边缘可以画城池一角（如襄阳），城池只当背景，逻辑上是峭壁。
- **格子比例**：平原 49%、丘陵 22%、水 10%、森林 10%、峭壁 9%。
- **打法**：战场被两侧山坡收窄成一条走廊，侧翼靠山。过河点是双方争夺的焦点。
- **变体**：
  - **⑥北（渭水）**：黄土台塬、旱地。
  - **⑥南（汉水）**：绿色、稻田、渡船。
  - 两种都在第一轮做。
- **素材**：中等河流水面、台塬或梯田、桥、渡船、山坡、城池一角。
- **路线**：长安—天水（⑥北），江夏—襄阳、宛城—襄阳（⑥南）（共 3 条），外加特例：从汉中攻长安（⑥北）。

### ⑦ 北方山丘

- **原型**：
  - 太行山：晋阳—邺走滏口陉，晋阳—洛阳走太行陉（天井关）。
  - 沂蒙丘陵南缘：北海—下邳。
  - 方城隘口：宛城—许昌，是伏牛山和桐柏山之间的缺口。
- **画面**：灰褐色的裸岩，黄土沟壑和台地，稀疏的松柏和灌木，干涸的河床，旱作梯田。冷灰配土黄，有冬天的感觉。
- **布局**：
  - 中部一条蜿蜒的谷道（陉）横贯左右，宽 4–8 格，大致在 y 12–20 之间。
  - 谷道两侧是成片丘陵，夹着几段岩壁。
  - 另有 2–3 条 1 格宽的山间小径，翻过丘陵通往高地。
  - 干河床在逻辑上算平原，只有少量山泉小塘是水。
- **格子比例**：
  - ⑦太行：平原 35%、丘陵 35%、峭壁 15%、森林 10%、水 5%。
  - ⑦丘陵：平原 35%、丘陵 45%、森林 12%、峭壁 5%、水 3%。
- **打法**：骑兵在丘陵上移动成本高，只能走谷道。步兵和精锐抢高地。站在丘陵上可以对谷道里的敌人用落石。
- **变体**：
  - **⑦太行**：更陡，峭壁更多。第一轮先做。
  - **⑦丘陵**（沂蒙、方城）：更缓，丘陵多、峭壁少。第二轮做；做好之前先用 ⑦太行。
- **素材**：裸岩、黄土沟壑、松柏、干河床、旱作梯田、山间小径。
- **路线**：晋阳—邺、晋阳—洛阳（⑦太行），北海—下邳、宛城—许昌（⑦丘陵）（共 4 条）。

### ⑧ 南方丘陵

- **原型**：
  - 四川盆地丘陵：成都、江州、梓潼之间，沿涪江、嘉陵江。
  - 荆门—当阳丘陵：江陵—襄阳，208 年长坂坡就在这条路上。
  - 大别山南北麓：江夏—寿春。
  - 皖南、江南丘陵：柴桑—吴。
- **画面**：浑圆连绵的绿色丘陵，竹林、阔叶林、水田梯田、溪流和小水塘、红土或紫色土小路、山间村落。空气湿润，有雾。
- **布局**：
  - 全图散布 6–10 个圆丘，每个约 4×4 格。
  - 丘间是低洼田地和小路。
  - 一两条 1 格宽的溪流，大片竹林和树林，没有大河。
  - 加一段从攻方一侧缓缓上升、约 12 格长的长坡，取"长坂坡"的意象。
- **格子比例**：平原 40%、森林 25%、丘陵 25%、水 8%、峭壁 2%。
- **打法**：视线遮挡多，是伏兵和火攻（林地火攻 ×1.4）的主场。骑兵会被林地拖慢。
- **素材**：圆丘、竹林、阔叶林、水田梯田、溪流、红土小路、山间村落、雾气。
- **路线**：成都—江州、成都—梓潼、江州—梓潼、柴桑—吴、江陵—襄阳、江夏—寿春（6 条）。

### ⑨ 峡谷栈道

- **原型**：
  - 秦岭褒斜道：长安—汉中。
  - 祁山道、西汉水：汉中—天水。诸葛亮北伐出祁山，走的就是这一带。
  - 汉水上游峡谷：汉中—襄阳，经过安康。
  - 三峡：江陵—江州。
- **画面**：深峡，两侧是绝壁，有云雾和悬崖上的松树，谷底是急流。崖壁上凿孔架着木栈道，谷中偶尔有一小块河滩平地。青灰、墨绿色调。
- **布局**：
  - 峡谷左右横贯。上下两侧 y 0–8 和 y 23–31 是大片峭壁。
  - 谷底河流在 y 14–16，有两座木桥。
  - 河两岸 y 9–13 和 y 17–22 是河滩，夹着突出的岩壁，最窄处只剩 1–2 格宽的栈道。
  - 中段 x 18–29 有一块开阔谷地（谷口小盆地，向上下延伸到 y 6–25），作为主战场。
  - 一两条侧谷通往高处的丘陵台地（约 y 2–6），可以伏兵或用落石。
- **格子比例**：峭壁 45%、平原 22%、丘陵 15%、水 10%、森林 8%。
- **打法**：通道极窄，大军施展不开，可以以少胜多。骑兵几乎派不上用场。
- **变体**：
  - **⑨峡谷**：第一轮先做。
  - **⑨三峡**：江面更宽（约 y 12–19，沿江不横渡），栈道换成江边的纤道，水军可以从江上推进。第二轮做；做好之前先用 ⑨峡谷。
- **素材**：绝壁、峡谷急流、木栈道、河滩、悬松、云雾、侧谷台地；⑨三峡另加纤道。
- **路线**：长安—汉中、汉中—天水、汉中—襄阳（⑨峡谷），江陵—江州（⑨三峡）（共 4 条）。

### ⑩ 雄关隘口

- **原型**：
  - 潼关、函谷关：长安—洛阳，崤函古道。
  - 虎牢关（汉代称成皋）：洛阳—陈留。
  - 剑门关：汉中—梓潼。
  - 桐柏山口：许昌—江夏。
  - 伊阙关、轘辕关：洛阳—宛城。184 年东汉设"八关"拱卫洛阳，这两座都在其中。
- **画面**：两山夹峙，中间一道关城。夯土或砖石关墙横断山口，上有城楼、城门。关前是缓坡和开阔地，关后有道路通往守方。
- **布局**：
  - 上下两条山带 y 0–6 和 y 25–31：x 0–25 一段是丘陵，x 26–47 一段是峭壁。
  - 关墙在 x 30（1 格厚），从 y 5 连到 y 26，两端接峭壁。
  - 主城门 y 14–16（3 格宽），在大路上；南面 y 21–22 是 2 格宽的侧门，有小路连到关前和关后。
  - 关前 x 14–29 是缓坡开阔地，关后 x 32–47 是道路和守方营地。
  - 一条 1 格宽的险峻小道，穿过上方山带绕过关隘，全长约 25 格。
- **格子比例**：平原 40%、峭壁 25%、丘陵 25%、森林 10%、水 0。
- **打法**：攻关战。主城门是唯一的宽口，守方要同时堵主门和侧门；弓兵可以隔墙对射，绕路小道可以出奇兵。
- **规则说明**：现有规则里没有城墙、城门状态，也没有攻城器械。关墙只是不可通行格，城门是普通格，不能关门。以后如果想做"关门/破门"，需要改规则。
- **素材**：关墙、城楼、城门、关前缓坡、绝壁、险峻小道。
- **路线**：长安—洛阳、洛阳—陈留、汉中—梓潼、许昌—江夏、洛阳—宛城（5 条）。

## 10. 出图流程（每张重复一次）

1. **写格子布局**。格子布局写成 48×32 的字符数据，每行 48 个字符：`.` 平原、`T` 森林、`^` 丘陵、`~` 水、`#` 峭壁。部署区和营地另外标出。出图阶段，布局写在 `tools/build-battlefield-art.mjs` 里，输出到 [battlefield-art/](battlefield-art/README.md)；接入游戏时再导入 `battle/battlefields/`。
2. **自动校验**。检查以下几项：
   - 尺寸是否正确；
   - 部署区不在水或峭壁上；
   - 双方营地之间有路可通；
   - 主要渡河点符合 B4；
   - 格子比例在目标 ±5% 以内。
3. **导出布局参考图**。由布局数据自动生成 1536×1024 的色块图（每格 32px），做法和之前大地图用的 [layout guide](assets/campaign-layout-guide-v01.png) 一样。
4. **写提示词**。由"画风固定段"加"本战场段"组成。
5. **出图**。你在 ImageGen（之前用的 Codex 内置工具）里出 1536×1024，每张出 3–4 张候选，选一张。我这边没有出图工具；布局图、提示词、对齐和接入由我来做。
6. **放大与对齐**。放大到 3072×2048，把格子叠在画上检查。画和格子对不上的地方，优先改格子；格子不能改的（会破坏校验），就局部重绘。
7. **预览**。在开发模式的战场预览页里叠加格子、部署区和营地，截图给你过目。
8. **入库**。压缩成 WebP，登记资源清单，提示词记入 provenance。

每张图都要你确认后，再做下一张。

## 12. 验收标准

- **规则**：`battle.test.ts` 中和规则相关的测试，不改期望值就能通过。只有和尺寸相关的断言需要更新。
- **节奏**：用 `npm run diagnostics:battles` 测，每种战场 200 个种子。
  - 首次接敌中位数 ≤ 4 天（现在 2 天）。
  - 战斗天数中位数 ≤ 12（现在 8–9），p90 ≤ 16（现在 10）。
  - 打满 30 天的比例不高于现在。
- **性能**：
  - 10 对 10 的 AI 战斗日，p95 < 50 ms（沿用 `performance.test.ts` 的现有标准）。
  - 拖动和缩放流畅。
- **存档**：旧存档里进行中的 24×20 战斗能读取，也能继续打。
- **画面**：
  - 100% 缩放时头像清晰可辨，最小缩放能看全图。
  - 1366×768 和 1920×1080 下，侧栏不遮挡部署区。
- **资源**：每张幕布 ≤ 1.5 MB，进入战斗时才加载。

## 13. 风险

| 风险                | 影响                                                                                              | 应对                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 寻路变慢            | 现在的寻路是按 480 格写的简单实现（`rules.ts` 的注释写明了），1536 格大约慢 10 倍，可能超出 50 ms | P2 先测；超了就改用堆实现，平局规则不变，结果完全一致                 |
| AI 在关隘或峡谷卡住 | 窄口地图上 AI 可能挤成一团，或者一直不进攻                                                        | 每张图都跑节奏诊断；必要时调整布局（比如加宽通道），不改 AI           |
| 出图对不齐格子      | AI 出图很难精确到每一格                                                                           | 用布局参考图约束；能改格子就以画为准；不能改的局部重绘                |
| 地图显得空旷        | 兵少时（比如 3 对 3）画面空                                                                       | 地形特色集中在主战场；开战时镜头先对准双方部署区                      |
| 存档变大            | 每场战斗都存整张地图，1536 格约 12 KB；保留最近 100 场约 1.2 MB                                   | 仍远低于 16 MiB 上限。以后如果需要，历史记录可以只存战场 ID，不存格子 |
| 资源体积            | 15 张 × 1.5 MB ≈ 22 MB                                                                            | 进入战斗时才加载，不放进首屏                                          |
